# 🚀 Digital Grievance Portal

A modern and responsive grievance management platform that enables citizens to submit complaints, track grievance status, and manage their profiles through an intuitive dashboard.

---

## 📖 Overview

The **Digital Grievance Portal** is designed to simplify communication between citizens and government departments. Users can submit grievances, track their status, and view complaint history through a clean and user-friendly interface.

This project was designed in **Figma** and implemented using **React.js** and **Tailwind CSS**.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/M-Poojitha04/digital-grievance-portal
```

Navigate into the project:

```bash
cd digital-grievance-portal
```

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```
